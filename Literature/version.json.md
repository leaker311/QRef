# version control

# We cannot trust the wifi capabilities always so we

# need to always load from cache and then quietly look at the server

# in the background for data changes that need to be pulled down

# we have both text and pictures and later on maybe other file formats so we need

# a way for the app to see when updates have been made so we can sync

# the most robust way is to use a version file like this that keeps track of the version and if

# there is a new one the app will let us know

# FAILURE point is that the administrator, after updates to the data MUST update the version number in this file

# otherwise the app is unaware of the changes
